# Data dictionary

All data is fictitious, generated by `generate_tickets.py` (fixed seed, reproducible).

| Column | Type | Description |
| --- | --- | --- |
| code | STRING | Ticket id, `YYYY-MM-NNNNN` |
| title | STRING | Short description of the issue |
| category | STRING | GUARANTEE, TECHNICIAL_SUPPORT (sic, the typo mirrors real systems), TECHNICAL_VISIT, MAINTENANCE, INSTALLATION, CONFIGURATION, ASSET_REMOVAL, TECHNICIAL_REPORT |
| status | STRING | OPENED, STARTED, SCHEDULE, PENDING, AWAITING_TECHNICIAN_LINK, PART_PREPARATION, PART_SHIPPED, CONCLUDED, FINISHED, NOT_SOLVED, CANCELLED |
| priority | STRING | URGENTE, ALTA, MEDIA, BAIXA |
| created_at | STRING (ISO 8601, UTC) | When the ticket was opened |
| concluded_date | STRING (ISO 8601, UTC) | When it was closed. **Empty string when open**, not NULL: a deliberate data-quality trap |
| equipamento | STRING | Equipment model |
| tecnico | STRING | Fictitious technician name (may be empty) |
| root_cause | STRING | Only for GUARANTEE: FACTORY_DEFECT, NATURAL_WEAR, OPERATIONAL_ERROR |
